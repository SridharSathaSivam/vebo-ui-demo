# Vebo UI Demo

Live demo for the Vebo UI native Web Component library.

See [`getting-started.md`](./getting-started.md) for the complete setup and usage guide.

## Framework examples

- [React](./frameworks/react/README.md)
- [Vue 3](./frameworks/vue/README.md)
- [Angular](./frameworks/angular/README.md)
- [Svelte](./frameworks/svelte/README.md)

## Native HTML

The root demo uses Vebo components directly as Custom Elements. The same components are consumed by frameworks through generated adapters, without changing the underlying DOM-native API.
